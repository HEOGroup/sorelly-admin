Layout 1. Uma tabela só. Cada mês é uma linha. Clique na linha para abrir os detalhes. Meses fechados, mês em andamento e meses previstos ficam em faixas separadas.

Layout 2. Escolha o mês. A tela mostra duas tabelas lado a lado: o que entra e o que sai. A conta fecha no resultado. Mês futuro usa a mesma tela.

Layout 3. Todos os meses lado a lado, como uma linha do tempo. A linha dourada marca o mês de hoje. Os meses previstos têm fundo listrado. Clique no nome do mês para abrir os detalhes embaixo.

Layout 4. O resultado do mês passo a passo, de cima para baixo. Cada linha soma ou subtrai. A barra mostra quanto cada passo pesa. Serve para explicar de onde veio o resultado.

Meses de janeiro a outubro: números lidos da tela Resultado do mês em 02/11/2026 (DevMaster). Novembro: previsão da tela. Dezembro a abril: entrada de EXEMPLO, só para mostrar o desenho. A tela de hoje mostra zero acertos nesses meses, porque novembro ainda não tem faturamento lançado. A saída desses meses é o que já está lançado até hoje.
