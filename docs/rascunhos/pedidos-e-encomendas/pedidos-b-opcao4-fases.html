Pedidos · opção 4 com fases em cor

Mesmo cartão que abre da opção 4. Novidades: uma barra no alto com as 3 fases (Compra, Banho e Empresa), cada uma com a sua cor, que acompanha as colunas quando a tela rola para o lado. A mesma cor aparece no topo de cada coluna, no número da etapa e na borda do cartão. Dá para saber a fase de relance. Vermelho continua só para atrasado e dourado só para botão e aba. O zoom no topo vale para a tela inteira. Dados de exemplo, inventados.
