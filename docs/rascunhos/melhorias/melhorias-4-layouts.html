Solicitações de melhorias · 4 layouts

Cada layout mostra três momentos: tela normal, nova solicitação e conversa (o chat de cada pedido). Clique nos botões para trocar. Nomes e pedidos são de exemplo.

Tudo no padrão do sistema: fonte 13 px, campos de 32 px, cabeçalho dourado com linhas de corte, só o texto de situação leva cor. A conversa usa o mesmo estado de hoje (pedido + mensagens). Quem gerencia (Marcus, Nickolas, Lucas, Leonardo) muda a situação.
