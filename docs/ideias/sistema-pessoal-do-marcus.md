# Sistema pessoal do Marcus (fora do admin da empresa)

**Situação:** decidido fazer depois (02/11/2026).

## O que é
Hoje o menu do admin tem uma área pessoal do Marcus (Resumo, Faturamento, Patrimônio e dívidas, Contas do mês, Extratos, Atividades, Acessos e senhas, Dados: telas `marcus*` em `navigation/setores.js`).

## Decisão do Marcus (02/11/2026)
"Área Marcus pode deixar por enquanto; depois eu faço um sistema separado."

## Regra que já vale
Extratos e assuntos pessoais do Marcus ficam só no sistema pessoal, nunca no Admin da empresa.

## Quando fizer
- Criar um projeto próprio em `C:\Projetos` (como o Zenity App), com Git próprio e privado.
- Levar as telas `marcus*` e os dados de `docs/dados-locais/pessoal/`.
- Tirar a área do menu do admin depois que o sistema novo estiver funcionando.
