# Referência

Os dois HTMLs originais, intactos, como estavam antes da reestruturação.

Servem para conferir qualquer dúvida sobre o comportamento anterior: abra um
deles direto no navegador e compare com a versão nova rodando em `npm run dev`.

- `montagem-bipagem.original.html` → virou `src/apps/montagem/`
- `kits-novos-curitiba.original.html` → virou `src/apps/kits-novos/` (os ~2.000
  registros que estavam na linha 400 viraram `public/dados/kits-novos-curitiba.json`)

Nada aqui é compilado nem entra no build.
